# ADR-008: Web pra escrever, celular pra revisar

- **Status:** Aceita
- **Data:** 2026-11-23

## Contexto

A jornada mostrou que escrever nota pede teclado e tempo, e revisar cabe em poucos minutos em qualquer lugar.

## Decisão

Web é o lugar de escrever, organizar, estudar a fonte e configurar. O celular (PWA) abre na revisão do dia, permite ler notas e fazer pequenas correções.

## Alternativas consideradas

App nativo desde o início (adiado: PWA basta pra começar).

## Consequências

A tela inicial do celular é a revisão do dia com lembrete; o editor completo é otimizado pra desktop.
